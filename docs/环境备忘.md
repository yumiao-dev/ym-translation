## 一、训练平台

### 1.1 平台选择

| 尝试过的方案 | 结果 |
|---|---|
| 阿里云 DSW | ❌ cookie 失效 / 无法稳定注入 |
| **ModelScope Code Workspace** | ✅ **最终采用** |

**入口**：`https://www.modelscope.cn/code/workspace`

只需 ModelScope 登录态，无需额外配置。

### 1.2 实例规格

| 项 | 值 |
|---|---|
| 规格名 | DSW-AMD |
| 加速卡 | AMD Instinct MI300A（APU） |
| 显存 | 191.7 GB |
| ROCm/HIP | 7.2.53211 |
| CPU | Intel Xeon，23 核 |
| 内存 | 200 GB |
| 存储 | 天翼云 NAS，1.0 PB 配额 |

**关键特性**：MI300A 是 APU 统一内存架构——CPU 和 GPU 共享物理内存，
数据加载不需要 PCIe 拷贝。这是本项目达到 213K tok/s 的重要原因之一。

### 1.3 ROCm 说明

- `torch.cuda.is_available()` 返回 **True**（ROCm 走 CUDA 兼容接口）
- `torch.version.hip` 返回 `7.2.53211`
- `torch.cuda.get_device_name(0)` 可能返回**空字符串**（ROCm 已知问题）
- `nn.RMSNorm` 在部分 ROCm 版本需 shim，本项目用 `rmsnorm_shim.py` 兜底

## 二、实例会自动关闭（重要）

**ModelScope Code Workspace 实例约 1 小时无操作会自动关闭。**

### 尝试过但失败的方案

| 方案 | 失败原因 |
|---|---|

   ```bash
   tmux new-session -d -s t2 "cd /mnt/workspace/ym-Translation && python3 scripts/train_trans2.py > /tmp/train2.log 2>&1"
   ```
2. **监控用浏览器自动化** —— 连进 Web IDE 的终端读日志
3. **人肉定期查看** —— 每小时检查一次

## 三、Web IDE 终端自动化（技术细节）

如果要自动化读取 Web IDE 的终端输出，以下是踩过的坑。

### 3.1 终端在 iframe 内

顶层 `document.querySelector('.xterm')` **查不到**，必须遍历 iframe：

```javascript
(function(){
  var fs = document.querySelectorAll("iframe");
  for (var i = 0; i < fs.length; i++) {
    try {
      var d = fs[i].contentDocument;
      if (!d) continue;
      var r = d.querySelector(".xterm-rows");
      if (r && r.innerText) return r.innerText;
    } catch(e){}
  }
  return "";
})()
```

### 3.2 终端只有 8 行可见

`.xterm-rows` 的 DOM **只保留 8 行**（不是滚动缓冲区）。
所以**大文件必须切片读**——每片不超过 ~500 字节。

### 3.3 命令输入需要聚焦

必须先点击 xterm 的 textbox（无障碍树里是 `textbox "终端 1，bash 运行命令…"`）
才能发送键盘输入。

### 3.4 heredoc / printf 重定向会失效

| 方式 | 结果 |
|---|---|
| `cat << 'EOF' > file` | ❌ `EOF` 终止符不被识别（被 bracketed paste 包裹） |
| `printf '...' > file` | ❌ 重定向符被吞 |
| **`echo -n '<base64>' >> file`** | ✅ **可靠** |

**推荐传输方式**：本地 base64 → 分片（每片 ≤600 字符）→ `echo -n >> file` 追加 → `base64 -d`

### 3.5 换行会被吞

多行命令要写成**单行**，或用 `;` 连接。

## 四、训练相关的坑

### 4.1 LR 调度必须基于相对步数（★）

续训时若沿用绝对步数，`step=3814` 时 `p≈0.47`，
LR 已经在余弦中段，会**立刻衰减到谷底**。

```python
# ❌ 错误
p = step / TOTAL_STEPS

# ✅ 正确
def get_lr(step, start_step):
    rel = step - start_step
    if rel < WARMUP:
        return LR_PEAK * rel / WARMUP
    p = (rel - WARMUP) / max(1, (TOTAL_STEPS - start_step) - WARMUP)
    return LR_MIN + 0.5 * (LR_PEAK - LR_MIN) * (1 + math.cos(min(p, 1.0) * math.pi))
```

### 4.2 TARGET_TOKENS 是累计总量（★）

`TARGET_TOKENS=4000000000` 表示"**包含已训 2.0B，总共训到 4.0B**"，
不是"再训 4.0B"。

### 4.3 数据通配符不匹配（★最严重）

```python
# ❌ 实际文件名是 ord_*.bin(44) + prag_*.bin(20)
#    part_*.bin 一个都匹配不到 → 8.4GB / 64 个文件被全部忽略
DATA_GLOBS = [".../data/tokens2/part_*.bin"]

# ✅
DATA_GLOBS = [".../data/tokens2/*.bin"]
```

**症状**：日志显示 `group1 tokens2: 0 parts`
**修复效果**：`0 parts` → `64 parts`，吞吐 42K → 213K tok/s

### 4.4 吞吐口径陷阱

日志里的 `213K tok/s` = `累计token ÷ 本次启动耗时`，
分子**含历史存量**，所以续训刚启动时会虚高到 `81564K tok/s`。

**真实速度看步进速率**：4.7 秒/步 × 524,288 tok/步 = **111K tok/s**（稳态）。

### 4.5 中文必须去空格

原语料中文列带分词空格（`表演 前 ， 她`），必须删掉：
- BPE 词边界靠空格标记，中文带空格会被**切碎**，多字词学不出来
- 实测无空格版 **token 效率高 2.4 倍**
- 输出更自然（否则模型会生成 `表演 前 ，` 这种怪异中文）

### 4.6 Chunked Cross-Entropy

`[B, T, 32000]` 的 logits 矩阵会 OOM，必须分块计算：

```python
def chunked_ce(head, x, targets, chunk=1024):
    B, T, C = x.shape
    xf = x.reshape(B * T, C)
    tf = targets.reshape(B * T)
    total, n = 0.0, 0
    for i in range(0, B * T, chunk):
        lg = head(xf[i:i+chunk])
        total += F.cross_entropy(lg.float(), tf[i:i+chunk], reduction='sum')
        n += tf[i:i+chunk].numel()
    return total / max(n, 1)
```

## 五、评估相关的坑

### 5.1 机翻基线要跑在 GPU 上

OPUS-MT + `num_beams=4` 在 **CPU 上极慢**：
- 本地 CPU：第 1 句就要 **507 秒**，13 句要 2 小时+
- 实例 GPU（MI300A）：13 句总共 **50 秒**（0.22–3.30 s/例）

**差约 500 倍。** 一定要在实例上跑。

### 5.2 OPUS-MT 参数量

`Helsinki-NLP/opus-mt-zh-en` 实测 **77.9M 参数**（官方标称 ~74M）。

### 5.3 实例下载模型

```bash
export HF_ENDPOINT=https://hf-mirror.com
python3 -c "
from transformers import MarianMTModel, MarianTokenizer
tok = MarianTokenizer.from_pretrained('Helsinki-NLP/opus-mt-zh-en')
mdl = MarianMTModel.from_pretrained('Helsinki-NLP/opus-mt-zh-en')
tok.save_pretrained('opusmt_zh_en'); mdl.save_pretrained('opusmt_zh_en')
"
```
