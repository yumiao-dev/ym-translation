# 中英平行语料数据集清单（候选中）

## A. ModelScope 上可直接下载（免翻墙）
| 数据集 | 规模 | 说明 | 优先级 |
|---|---|---|---|
| iic/WMT-Chinese-to-English-MT-Training-Corpus | 6.36GB / 630万句 | 已下载已tokenize | 已有 |

| **Mxode/BiST** | **29.2GB / 5962万** | 多LLM生成+验证，自带dev | ★★★★★ |
| Helsinki-NLP/opus-100 (zh-en) | ~2GB / 1000万 | 多源混合 | ★★★★ |
| Helsinki-NLP/un_pc (en-zh) | ~5GB / 1731万 | 联合国文件，人工翻译，质量极高 | ★★★★★ |

| translation2019zh | 1.3GB / 520万 | 中英，老牌 | ★★★ |
| News-Commentary v16 | 67MB / 40万 | 新闻评论 | ★★★ |
| WikiMatrix (zh-en) | 0.6GB / 百万级 | 维基百科 | ★★★ |
